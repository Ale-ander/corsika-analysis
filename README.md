# Corsika Analysis

Scripts to analyze and convert [CORSIKA 7](https://web.iap.kit.edu/corsika) output files.

Converter output format is CSV.

Based on P. Savina code for [Corsika hands-on course](https://gitlab.com/psavina_public_projects/corsika-hands_on). 

### Requirements
- Make
- Corsika
- root
- gcc
- numpy
- [corsikaio](https://pypi.org/project/corsikaio/)
- [particle](https://pypi.org/project/particle/)
